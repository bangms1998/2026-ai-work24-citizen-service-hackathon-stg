자주 묻는 질문

공모전 관련 주요 질문과 답변을 확인하세요.

1. 참가 자격

Q1학생이나 취업준비생만 참가할 수 있나요?

아닙니다. 서비스 기획 및 개발에 관심 있는 만 19세 이상 대한민국 국민이라면 직업이나 소속에 관계없이 참가할 수 있습니다. 다만 국내 거주자에 한하며, 기업 명의로는 참가할 수 없습니다.

Q2개인으로도 참가할 수 있나요? 팀은 몇 명까지 가능한가요?

개인 또는 팀으로 참가할 수 있습니다. 팀은 2명 이상 4명 이내로 구성해야 하며, 팀당 1개의 아이디어만 제출할 수 있습니다.

2. 공모 주제·개발 범위

Q3어떤 서비스를 제안해야 하나요?

AI 기술을 접목하여 국민이 체감할 수 있는 고용24 관련 서비스를 제안해야 합니다. 1차 접수 단계에서는 아이디어 기획안을 제출하며, 서류심사를 통해 선정된 20팀은 제안한 아이디어를 바탕으로 웹 서비스 형태의 MVP를 개발하게 됩니다.

Q4MVP는 어느 정도까지 구현해야 하나요?

MVP는 모든 기능을 갖춘 완성형 서비스가 아니라, 핵심 기능을 구현해 실제 작동 여부와 실현 가능성을 검증할 수 있는 최소 단위의 제품을 의미합니다. 따라서 단순한 화면 시안에 그치기보다, 주요 이용 흐름과 제안한 서비스의 핵심 기능이 실제로 작동하도록 구현해야 합니다.

Q5AI 기술을 반드시 활용해야 하나요?

네. 제안하는 고용24 서비스의 핵심 기능에 AI 기술이 활용되어야 합니다. AI 기술을 활용하지 않은 작품은 심사에서 제외됩니다. 아이디어 기획안에는 해결하려는 문제와 AI 기술의 활용 방식이 구체적으로 드러나도록 작성해 주시기 바랍니다.

Q6생성형 AI플랫폼이 뭔가요?

선정된 20팀이 MVP 개발 시 활용할 수 있도록 제공하는 LLM 기반 개발 환경입니다. 별도의 서버나 모델 구축 없이 API방식으로 생성형 AI 기능을 호출해 서비스에 바로 접목할 수 있는 형태로 제공됩니다. 세부 제공모델, 이용한도, 접속방법은 1차 심사 통과팀 대상 설명회에서 안내드립니다.

Q7개인 참가자가 일부 OpenAPI의 인증키를 발급받기 어려운 경우에는 어떻게 활용해야 하나요?

고용24 OpenAPI 중에는 채용정보와 같이 신청 자격이나 이용 권한이 제한되어 개인 참가자가 인증키를 발급받기 어려운 API가 있을 수 있습니다. 이러한 경우에는 해당 API의 실제 데이터를 직접 연동하는 대신, 공개된 API 명세와 데이터 구조를 참고하여 실제 데이터와 유사한 형태의 모의데이터(합성데이터)를 생성해 활용해 주시기 바랍니다.

  • 1차 접수 단계에서는 API 인증키 보유 여부와 관계없이 공개된 API 명세와 데이터 구조를 기준으로 데이터 활용 명세서를 작성해 제출할 수 있습니다.
  • 1차 서류심사를 통과한 후 2차 서비스 개발 단계에서도 동일한 모의데이터를 활용해 MVP를 개발할 수 있습니다.
  • 소속 정보 기재를 요구하는 등 개인 신청 권한 밖의 API는 별도로 신청하지 않고, 필요한 데이터는 모의데이터(합성데이터)로 구현해 주세요.
  • 데이터 활용 명세서에는 해당 데이터가 ‘모의데이터’임을 명확히 기재해 주세요.
Q8고용24 OpenAPI 요청 시 비정상적인 호출을 시도하면 어떻게 되나요?

안정적인 서비스 운영과 보안 유지를 위해 시스템 정책에 위배되는 비정상 접근 및 이상 트래픽은 실시간 모니터링 시스템을 통해 감지되며, 사전 통지 없이 즉시 접속 IP가 차단될 수 있습니다.

주요 즉시 차단 사유는 다음과 같습니다.

  • API Endpoint 임의 변경 및 변조: 공지된 공식 오픈 API URL 규격을 준수하지 않고 파라미터나 엔드포인트를 임의로 조작하여 호출하는 행위
  • 유효하지 않은 인증 정보 사용: 정상적으로 발급된 인증키(API Key) 없이 임의의 난수 값을 입력하거나, 위조·변조된 인증 정보를 포함하여 요청을 전송하는 행위
  • 자동화 도구를 통한 이상 호출: 매크로, 스크립트, 크롤러 등 자동화 도구를 이용해 비정상적인 빈도로 요청을 전송하거나 시스템 부하를 유발하는 이상 트래픽을 발생시키는 행위
  • 비인가 접근 및 보안 위협 시도: 인증 절차 우회 시도, 무차별 대입(Brute Force), 취약점 스캐닝 등 공격 행위로 판단되는 모든 호출
